Audio Manager Extension

Created by Niilisto (Nihil) - 2026

Description

The Audio Manager is a high-performance audio channel state machine for Clickteam Fusion 2.5. It manages states such as volume, frequency sweeps, LFO modulations, ADSR volume envelopes, and playlist queues internally in C++, and communicates back to Fusion using trigger events (the Command Bridge).

Wildcard Options

  • Channel -1: Modifies or listens to all 48 channels at once.
  • Channel 0 (Play): Instructs Clickteam Fusion to play on the first free channel available.
  • Frequency 0 (Play): Plays the sample at its native rate/pitch.
